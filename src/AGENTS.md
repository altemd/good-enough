# src

Repo-wide invariants and the directory map: `../AGENTS.md`.

The application source. TanStack Start (React 19 + TypeScript) with Nitro's
Node adapter.

## Layout

- `routeTree.gen.ts` — generated by TanStack Router. **Never hand-edit.** Run
  `pnpm generate-routes` after route changes and inspect the diff.
- `router.tsx` — router assembly (`scrollRestoration`, intent preloading).
- `start.ts` — the TanStack Start instance. Owns the CSRF request middleware:
  every `serverFn` call's origin must equal the configured `APP_ORIGIN`.
- `routes/` — file routes (see `routes/AGENTS.md`).
- `features/` — vertical feature ownership. One AGENTS.md per feature.
- `components/`, `lib/` — shared client primitives.
- `styles.css` — Tailwind 4 entry (excluded from Biome by design).

## Invariants

- **Server-only boundary.** Anything that touches the database, process env,
  credentials, or the inference backend imports
  `@tanstack/react-start/server-only` and lives in a `*.server.ts` file. Do not
  move secrets or process-only logic into modules reachable from the client
  bundle. Client code ships to the browser.
- **Feature ownership is vertical.** A feature keeps its server, functions,
  UI, schema, and tests together. Do not introduce generic global
  `controllers`/`services`/`repositories`/`utils` layers. Route files sit in
  `routes/` only because the file router requires that location.
- **Import aliases.** `#/*` and `@/*` both resolve to `src/*`. Application code
  uses `#/*`. `@/*` exists only so the generated `components/ui/` registry
  files keep their `@/lib/utils` import for clean `shadcn add` diffs.
- **Dependencies.** No scaffold add-ons and no new dependency without a
  demonstrated current need. Several core packages are prerelease/nightly pins
  (TanStack Start, Nitro nightly); pin and test upgrades deliberately.
- **Devtools are dev-only.** TanStack Devtools render only under
  `import.meta.env.DEV`. Production output must not carry them.
- **Build artifacts are untracked.** `.output/`, `.nitro/`, `.tanstack/`,
  `.pnpm-store/`, and `data/` are generated or private and never committed.
